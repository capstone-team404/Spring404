## Overview

여기지!는 사용자 리뷰와 공공데이터를 기반으로 위치별 안전도를 산출하고,  
이를 지도 위에 시각화하여 더 안전한 이동 경로를 추천하는 서비스입니다.

기존 지도 서비스가 거리와 시간 중심의 경로 탐색에 집중한다면,  
여기지!는 사용자의 실제 이동 환경에서 중요한 기준이 될 수 있는 '안전성'에 주목합니다.

AI 분석을 통해 리뷰 데이터를 정량화하고, 이를 지역 안전 정보와 결합하여  
사용자가 보다 안전한 경로를 선택할 수 있도록 지원하는 것을 목표로 합니다.

---

## Problem

기존 지도 서비스는 주로 최단 거리와 소요 시간을 기준으로 경로를 제공합니다.  
하지만 낯선 지역이나 늦은 시간대의 이동에서는 경로의 안전성이 더 중요한 판단 기준이 될 수 있습니다.

특히 여성 1인 여행자의 경우, 신뢰할 수 있는 안전 정보가 부족하면  
이동 자체에 대한 심리적 부담이 커지고 선택 가능한 동선도 제한될 수 있습니다.

저희는 이러한 정보 공백이 실제 이동의 제약으로 이어진다고 보았고,  
안전도를 반영한 지도 시각화와 경로 추천이 필요하다고 판단했습니다.

---

## Solution

본 프로젝트는 사용자 리뷰와 공공 안전 인프라 데이터를 결합하여, 사용자가 이동 전 특정 지역의 안전도를 직관적으로 확인할 수 있도록 지원합니다.

### 1. 안전 데이터 기반 지도 시각화

- 분석 대상 영역을 격자 구역(`zone_id`)으로 분할
- CCTV, 편의점, 경찰 시설, 보안등 데이터를 구역별로 집계
- 사용자 리뷰와 공공 안전 인프라 데이터를 기반으로 구역별 안전 점수 산출
- Google Maps 기반 안전도 시각화 제공

### 2. AI 기반 리뷰 분석

- 사용자가 입력한 위험/안전 경험 리뷰를 AI 서버로 전송
- 리뷰 텍스트를 기반으로 위험도 또는 안전도 점수 산출
- 사용자 평점과 AI 분석 점수를 결합하여 리뷰 기반 안전 점수 계산

### 3. 안전도 기반 경로 평가

- 프론트엔드에서 생성한 후보 경로의 좌표를 백엔드로 전달
- 각 경로가 지나는 구역의 안전 점수를 기반으로 경로별 안전도 계산
- 더 안전한 경로를 선택할 수 있도록 경로 후보를 안전도 기준으로 정렬

## MVP

본 프로젝트의 핵심 MVP는 데이터 기반 안전 지도(Safety Map)입니다.

### 핵심 기능

- 사용자 리뷰 데이터 입력
- AI 기반 리뷰 안전도 분석
- 공공 안전 인프라 데이터 연동 및 구역별 집계
- 구역별 안전 점수 산출
- Google Maps 기반 안전도 시각화
- 후보 경로별 안전도 평가 및 추천

### 결과

- 사용자는 특정 지역의 안전도를 지도에서 직관적으로 확인 가능
- “어디가 안전한가?”를 구역별 색상으로 판단 가능
- 출발지부터 목적지까지의 후보 경로 중 더 안전한 이동 경로 선택 가능

### 핵심 가치

- 여성 1인 이동 시 발생할 수 있는 불안감 완화
- 안전 정보를 기반으로 한 자율적 이동 의사결정 지원
- 단순 최단거리 중심이 아닌 안전 중심 경로 선택 지원

## Core Logic

### 안전 지도 생성 로직 (Safety Map Generation)

본 시스템의 핵심 로직은 사용자 리뷰 데이터와 공공 안전 인프라 데이터를 결합하여 구역별 안전 점수를 산출하고, 이를 지도 위에 시각화하는 것입니다.

### 1. 데이터 수집

- 사용자 리뷰 데이터
  - 위험/안전 경험 텍스트
  - 사용자 입력 평점
  - 리뷰 작성 위치 좌표

- 공공 안전 인프라 데이터
  - CCTV 위치 데이터
  - 편의점 위치 데이터
  - 경찰 시설 위치 데이터
  - 보안등 위치 데이터

### 2. 데이터 전처리

- 분석 대상 영역을 일정 크기의 격자 구역으로 분할
- 각 시설 좌표를 `zone_id`로 변환
- 시설 유형별 개수를 구역 단위로 집계
- 리뷰 작성 위치 좌표를 `zone_id`로 변환

### 3. 안전도 점수 계산

- 리뷰 기반 점수
  - 사용자 평점과 AI 분석 점수를 결합
  - 구역별 리뷰 평균 점수 산출

- 공공 안전 인프라 점수
  - CCTV, 편의점, 경찰 시설, 보안등 개수를 기반으로 산출
  - 시설 유형별 가중치를 적용하여 공공 안전 점수 계산

- 최종 안전 점수
  - 리뷰 기반 점수와 공공 안전 인프라 점수를 가중 결합
  - 리뷰 데이터가 없는 구역은 공공 안전 인프라 점수를 우선 사용

### 4. 안전 지도 생성

- `/map/zones` API를 통해 구역별 안전 점수 제공
- Google Maps에서 각 구역을 사각형 또는 히트맵 형태로 시각화
- 안전 점수에 따라 위험/주의/안전 구역을 색상으로 표현

- React 실행을 위한 기본 HTML 파일

- 프로젝트에 필요한 라이브러리 정보 관리
- 실행 및 빌드 스크립트 관리

- 헬스체크 API 제공
