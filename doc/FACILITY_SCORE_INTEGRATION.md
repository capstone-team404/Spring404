# 수집된 시설 정보를 지도 점수에 연결

2026-11-12, 기준 main `2676c2b`. 별도 촬영 모드가 아닌 일반 운영 계산 변경안입니다. 앞선 `hereji-score-evidence-fix.zip`의 시설-only 회색 정책을 대체하므로 두 ZIP을 섞지 마세요.

## 실제로 달라진 점

- 별도 `collected_facility`에 수집되어 있던 시설 현황을 점수와 연결합니다. 임의 지역별 점수, 예시 리뷰, 촬영 플래그를 넣지 않습니다.
- 지도·구역 상세·리뷰 저장 후 갱신·경로 비교가 동일한 구역 점수를 사용합니다.
- 시설 지표는 가상의 3점을 더하지 않고, 리뷰 완충은 3점·작성자 0.5명 분량으로 축소합니다. 별점/분석 80:20 및 리뷰/시설 70:30은 유지합니다.
- 리뷰 없이 시설 자료만 있어도 점수를 표시하며 `시설 지표 높음/보통/낮음`으로 구분합니다. 시설 지표가 낮다는 사실을 실제 위험이나 범죄 발생으로 단정하지 않습니다.
- 서비스 수집 반경 밖이며 리뷰도 없는 구역은 격자를 그리지 않고 원래 지도를 보여줍니다. 실제 자료 부족 구역의 회색 표현은 남겨 둡니다.
- UI 구성과 색상 경계(3.5/2)는 유지합니다. DB 자료를 덮어쓰거나 추가 OpenAI 모델 호출을 하지 않습니다.

## 시설 지표의 초기 계산 기준

`backend/facility_scoring.py`에 집중되어 있습니다. 수집된 자료의 가용성을 보여주는 초기 휴리스틱이며 사용자 평가나 실제 사고율로 검증된 범죄 예측 모델이 아닙니다.

| 요소 | 가중치 | 값 |
|---|---:|---|
| CCTV | 0.4 | `1-exp(-설치 지점 수/1)` |
| 편의점 | 0.3 | `1-exp(-지점 수/1)` |
| 가로등 | 0.1 | `1-exp(-개수/2)` |
| 보안등 | 0.1 | `1-exp(-개수/2)` |
| 경찰시설 접근성 | 0.1 | `max(0, 1-직선거리m/1000)` |

사용 가능한 요소에 대해서만 가중치를 정규화하고 5점 척도로 환산합니다. 위 가중치·척도는 설계 가정으로서 향후 검증과 조정이 필요합니다. 설치 개수와 시설 가까움이 실제 안전을 입증하지는 않습니다.

- 미수집·stale·추정 좌표 자료 제외.
- 일부 수집된 원천에서 0개는 부재가 입증되지 않았으므로 제외. 관측된 양수 개수만 사용.
- 경계 구역은 수집 반경 안에 있는 시설만 집계한 원천 현황을 사용.
- 현재 보안등은 주소 대표 위치로 추정된 자료라 지도 상세에서는 보이지만 점수에서는 제외됩니다. 현재 가로등 미수집도 감점하지 않습니다.
- 예전 수동 시설 점수와 개수는 `legacy_*` 필드로 보존하고 새 계산과 혼합하지 않습니다.

## 동일 운영 자료에 대한 읽기 전용 계산

공개 API 자료(2026-11-12): 전체 441개 구역, 공개 리뷰 30개. 새 계산에서는 초록 26, 노랑 140, 빨강 193, 반경 밖 무리뷰 82개(격자 없음)였습니다. 이 자료에서 반경 안에 점수 없이 남는 구역은 없었지만, 수집 실패나 stale 전환 시 회색이 생길 수 있습니다. 색 비율을 맞추기 위해 나눈 결과가 아니라 위 계산의 결과이며, 빨강은 시설 지표나 리뷰의 낮은 평가를 뜻합니다.

캡처 파일은 기존 Vercel UI를 실제 Chromium 브라우저에서 390×844 CSS 픽셀, 배율 3(1170×2532 PNG)로 실행했습니다. 공개 데이터를 이 코드로 재계산한 응답을 개발 미리보기에서 연결했습니다. 실제 TMAP 지도를 로드했으며 이미지 생성·색 합성은 사용하지 않았습니다. 운영 서버에 배포된 결과를 캡처한 것은 아닙니다. 모든 운영 쓰기 요청을 차단한 채 조회했고, 운영 리뷰는 수정하지 않았습니다.

## 반영 순서

1. 최신 main에 이 ZIP의 동일 상대경로 파일을 반영. 신규 `backend/facility_scoring.py` 필수.
2. Render backend와 Vercel frontend 재배포. AI 재배포·DB 마이그레이션·새 환경변수 불필요.
3. `/map/zones` 응답 `score_policy_version=facility-integrated-v1` 및 `facility_score_components` 확인.
4. 구역을 선택해 상세 점수와 지도 색이 일치하는지 확인. 캐시 없이 새로고침 후 포스터용 캡처.
5. 라이브 데모도 동일 접속 주소의 동일 계산을 사용합니다. 자료 갱신이나 리뷰 변경에 따라 색은 바뀔 수 있습니다.

제공한 캡처는 개발 계산 미리보기이므로, 최종 포스터를 배포 결과로 소개할 때는 반영 후 다시 캡처하는 것을 권장합니다. 점수의 정확성·불안 완화 효과를 검증 완료로 소개하면 안 됩니다.
